# E_SensorFlingApp

A simple Android sensor app for the Mobile Systeme exercise. The app measures horizontal shaking movement with the device sensor, stores the best score, shows it in a progress bar, and sends a notification when a new highscore is reached.

## Features
- Accelerometer-based fling/shake measurement
- Highscore and last attempt display
- ProgressBar with maximum value 5000
- Restart button
- Optional gravity decay through checkbox
- Notification on new highscore
